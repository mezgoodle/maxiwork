# NestJS

## Installation

```bash
$ npm install
```

## Running the app

```bash
# development
$ npm run start

# watch mode
$ npm run start:dev

# production mode
$ npm run start:prod
```

## Test

```bash
# unit tests
$ npm run test

# e2e tests
$ npm run test:e2e

# test coverage
$ npm run test:cov
```

# Prisma

## Example code

The documentation is available at [Notion page](https://prismaio.notion.site/Let-s-build-a-REST-API-with-NestJS-and-Prisma-94258f8a78d7460883d5b900f706e9ae).

## Installation

```bash
$ npm install -D prisma
```

## Initialize Prisma

```bash
$ npx prisma init
```

## Migration

```bash
$ npx prisma migrate dev --name init
```

## Run seed

```bash
$ npx prisma db seed
```

## Prisma Studio

```bash
$ npx prisma studio
```
